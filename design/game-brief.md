# Game Brief: Octoku (옥토쿠)

**One-sentence pitch:** 다트판처럼 생긴 팔각 보드에 1~8을 채워, 모든 링과 방사선과 구역이 8로 딱 맞아떨어지게 만드는 수도쿠.

## Core loop
- 빈 칸을 고른다. 그 칸의 링, 방사선, 구역이 빛난다.
- 후보를 추리해 1~8 중 하나를 넣는다. 확신이 없으면 메모해 둔다.
- 맞으면 단서가 늘고, 틀리면 실수 1회가 쌓인다.
- 64칸을 다 채우면 새 퍼즐로 넘어간다.

## Player goal & fail state — what "working" looks like
- 보드: 링 8겹 x 방사선 8줄 = 64칸. 구역 8개 = (안쪽 4링 / 바깥쪽 4링) x 사분면 4개.
- 이기는 조건: 링 8개, 방사선 8줄, 구역 8개(총 24줄)에 1~8이 각각 한 번씩 들어간다. 정답은 항상 하나뿐이다.
- 지는 조건: 정답과 다른 숫자를 3번 넣으면 그 판이 끝난다.

## MVP — what must exist to be the game
1. 팔각 보드 그리기: 링 8겹, 방사선 8줄, 구역 8개, 고정 시작 숫자
2. 칸 선택 하이라이트: 선택 칸의 링, 방사선, 구역과 같은 숫자를 강조 (원형 보드 가독성의 핵심)
3. 숫자 패드 1~8로 입력과 지우기 (고정칸은 수정 불가)
4. 오답 처리: 정답과 다르면 빨갛게 표시하고 실수 +1, 3번이면 실패
5. 퍼즐 생성기: 정답이 하나뿐인 퍼즐을 즉석에서 만들고, 시작 숫자 개수로 난이도 3단계
6. 메모(후보 숫자) 입력
7. 클리어/실패 화면과 다시 하기, 새 퍼즐

## Out of scope — not building this
- 멀티플레이, 온라인, 랭킹, 매일 퍼즐
- 힌트, 되돌리기 (첫 버전에는 없음)
- 링 회전, 대각 합 같은 변형 규칙 (기본 규칙이 재미있는지 확인한 뒤에 추가)
- 저장과 이어하기, 튜토리얼 영상 (한 화면짜리 규칙 설명만)

## Build order
1. 고정 퍼즐 하나로 보드 그리기, 칸 선택, 하이라이트 (가장 불확실한 부분: 원형 보드가 읽히는가)
2. 숫자 입력, 정답 비교, 실수 3회 규칙
3. 클리어/실패 화면
4. 퍼즐 생성기와 난이도 3단계
5. 메모 입력

---
**Who it's for / what they feel:** 5~10분 짬이 나는 퍼즐 팬이고, 칸이 딱 맞아떨어질 때의 차분한 쾌감을 느낀다.

**Art & audio direction:** 스테인드글라스처럼 면이 또렷한 평면 벡터 팔각 보드(아이콘은 SVG), 맑은 딸깍 효과음과 잔잔한 앰비언트.

**Reference game:** Good Sudoku. 칸 선택, 하이라이트, 메모 입력 흐름만 가져오고 보드 모양만 8각 동심 구조로 바꾼다.
